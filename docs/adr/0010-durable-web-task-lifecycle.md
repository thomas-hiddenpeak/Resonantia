# ADR-0010: Web长任务独立运行、可观察状态与恢复

**Status**: Proposed
**Date**: 2026-10-29
**Owners**: Resonantia maintainers
**Governing specs**: [Spec003](../../specs/003-webui/spec.md)、[Spec002](../../specs/002-voice-training/spec.md)、[Spec001](../../specs/001-voice-conversion-engine/spec.md)、[Spec004](../../specs/004-source-separation/spec.md)

**Implementation authorization**: 维护者在讨论真实阶段进度、任务留存、断线/刷新恢复、暂停继续及
服务重启恢复后，要求“先监控当前工作进度，完成后推进目标，对项目进行改进，不仅仅是推理部分”，
并明确要求训练/推理页面关闭后后台继续、重开能获取进展和状态。该指令授权按已讨论方案实施；
本记录保留Proposed作为正式ADR审查状态，不重复索取该范围内的实施授权。

## Context and decision drivers

旧转换是一条同步HTTP请求，只有浏览器计时，后台JobKind只包含training/step。关闭页面不等于
停止CLI，却会丢失结果接收；临时输出/日志随请求析构。训练已有后台线程与joint-full checkpoint，
但只有一个内存状态槽，页面只恢复活动训练，不能可靠找回关闭期间完成/失败的任务或服务重启状态。

2026-10-29用户实际261.577秒歌曲已完成两次清理和声线推理，却在混音时因正常重采样的3帧
舍入差超过旧2帧容差而失败，产物随请求被删除。观察记录见本地
`runs/Web_Task_Lifecycle_20261029/evidence/current-task.json`。必须先修正确性，再保存已完成工作。

## Decision

1. 任务生命周期属于Web后台，网页只是提交/查看/控制客户端。保留现有C++20/CUDA、原生CLI、
   单GPU互斥、Bearer边界，不引入Python、外部队列、数据库服务或WebSocket运行依赖。
   旧同步API保留兼容；新界面使用短提交响应、稳定任务ID和有界轮询，不维持整个模型计算的HTTP连接。
2. 在`runs/.web_tasks/`保存版本化任务元数据、固定输入、参数、阶段产物和日志。先落盘确认接受，
   后启动后台工作；缺磁盘空间、启动失败不能留下假running。元数据以同目录staging/fsync/rename提交，
   严格校验版本、长度、枚举、ID和目录包含关系，不能让请求选择任意文件路径或命令。
   不修改已发布Tom Cybersinger及正式训练资产。读历史不自动重跑或发布模型。
3. 状态区分preparing/queued/running/pause_requested/paused/interrupted/succeeded/failed/cancelled，
   状态响应含任务kind、输入/声线/配方摘要、创建/启动/结束时间、阶段、真实计数、最近进展时间、
   有界日志、可执行动作、结果与错误。阶段计数与存活状态分别表示；GPU利用率不能当进度。
   全局任务列表同时发现训练、转换和清理；页面关闭、另一浏览器、重开页面都可重新查询。
4. 转换成功先发布持久结果再标记succeeded，下载失败不改变任务成功状态。失败保留已完成阶段与
   错误记录。重新混音不重复分离和推理。结果接口按文件块输出并支持必要的浏览器Range读取，
   不把完整长音频重复缓存在HTTP内存中；原上传限制不因此放宽。
5. 控制请求绑定稳定ID和执行代次，重复请求幂等、迟到请求不能控制新任务。暂停在安全点保存后
   释放GPU，完成写入/发布不被半途打断，错误优先于暂停成功。正常取消与暂停含义分开。
   页面离开不发送暂停/取消；前端网络失败显示“状态暂不可确认”并重连，不能擅自宣布后台失败。
6. 训练复用joint-full完整G/D/optimizer/RNG/epoch/数据身份checkpoint。旧decoder/gan/joint没有
   等价恢复能力时必须明确标示，不把推理G当checkpoint。训练预处理、缓存、训练、索引和保存分别
   汇报真实进度；关闭期间结束也可找回结果/失败原因。重启后历史活动任务标记interrupted，不能
   沿用上次内存中的running，也不能无条件自动重开昂贵计算。
7. 推理/去和声等长阶段增加独立于Web的轻量操作观察/停止接口；CLI把结构化进度与安全点写入
   任务通道。库只处理领域计数/控制，不读取Web任务ID或HTTP状态。阶段产物验证完成后才能复用。
   分块恢复必须记录输入、模型/索引、参数、实现版本和边界/采样身份；保留全局时间轴、重叠拼接、
   F0上下文及确定采样语义。先做到完整阶段复用，再通过真实音频门禁交付阶段内分块恢复；未通过
   时不得把阶段重跑称作分块恢复，整体恢复目标仍未完成。
8. 持久结果必须有可见保留策略、容量界限和清理动作；活动/暂停任务、唯一恢复点与正式模型不得
   因自动清理删除。元数据与日志有上限，列表分页，内存不随任务历史或整曲时长无限增加。

实现细化：服务重启后先持久标记interrupted，再对已归属任务的原attempt控制文件请求安全停止，
防止原生子进程失去服务所有者后继续长期占用GPU。不创建替代旧通道，不按PID强杀，也不把
请求停止记作paused。原进程因管道I/O错误提前退出时，只能从此前完整提交的checkpoint继续，
未提交的进度可能需要重算；跨进程锁持续阻止重叠执行，退出后由用户显式继续。

## Alternatives considered

- 继续计时或模拟百分比：不能证明工作推进，不满足需求。
- 仅显示CLI原日志：没有任务生命周期、分块计数、可恢复结果，仍会丢失已完成工作。
- 仅保存在浏览器localStorage：不能跨浏览器或服务重启找回后台事实。
- 对同步请求简单加超时/强杀：会丢失长任务，违背安全点与训练checkpoint契约。
- 新增Python/Celery/数据库服务：本项目单GPU规模无需新增运行时，先用有界C++任务存储。

## Migration and rollback

先记录当前失败和工作树基线，保留上轮中文文件名修复。当前用户转换已结束且反馈失败，才开始编辑。
先红后绿修复混音舍入；然后独立实现任务存储和HTTP门禁，再接转换/清理、训练、网页任务中心、
真实进度及恢复。接口以新增方式迁移，旧客户端仍可同步调用；生产服务在验收前保持原版，隔离
测试服务不使用正式任务目录。所有GPU验证仅用现有真实短片段/少量训练步，不重跑长训练/整首转换。

部署前确认没有活动任务，备份服务/UI/配置并原子切换。回退只恢复程序与页面，不删除新任务、
素材、检查点或正式模型；旧版不能解析的新任务保留，需新版才能继续，不冒充旧版可恢复。
服务重启后的动作、磁盘不足和未完成写入都必须有明确失败状态及保留的可恢复数据。

## Verification and SDD impact

更新WEB-FR-014以及Spec001/002/004各新增控制契约和迁移说明。持续更新
[实施清单](../../specs/003-webui/task-lifecycle-20261029.md)、DESIGN、TRACEABILITY、PROJECT_STATE。

- host：格式/边界/路径、原子失败、状态机、幂等/迟到控制、阶段完成与暂停竞争、GPU互斥；
- HTTP：提交响应丢失后查询、关闭连接、日志/结果接口、Range、busy/磁盘/进程失败诚实性；
- browser：真实页面关闭/重开、任务运行与关闭期间终态、网络断开/恢复、跨标签与任务历史；
- restart：独立服务重启后interrupted、原产物保留、显式继续、非法身份/损坏checkpoint拒绝；
- real assets：短真实人声连续/暂停恢复输出对齐、分块边界与时长不变；joint-full短步完整状态恢复；
- 构建、相关CTest、浏览器、真实短片段与SDD检查有记录；skip与mock不当作真实模型通过。

## 2026-10-29 follow-up: completed audio revisions

维护者进一步指出完成任务改参数必须从头来过。本增量沿用上文独立任务及阶段产物机制：
旧任务不可变，新ID记录source_task，仅把身份/摘要验证且依赖未变化的完成阶段复制到新任务，
用新任务身份重新提交阶段标记。不是共享可变缓存，不改变块恢复、训练或运行时依赖。
细化契约及回退见Spec003 WEB-FR-014完成任务调整参数段；该缺陷修复授权来自维护者本次反馈。

## 2026-10-29 identity correction

维护者报告跨部署参数修订被身份校验拒绝。诊断已证明只有Web executable字段变化，计算CLI、
输入、模型与配方仍匹配旧完整摘要。Web身份改为显式编排版本；原生块身份继续绑定计算程序。
只重算并接受已审计的09:27/14:04两个旧Web可执行SHA对应的完整摘要，不按文件存在或错误文本
豁免验证，不修改旧记录/标记。训练Web与嵌套切片摘要同样处理。TaskArtifacts可选兼容摘要最多2项，
只由代码内受限身份构造器生成，客户端不能传入；持久格式不变。新编排若改变准备/混音/训练组织
数值行为必须提升协议版本，未知旧程序不自动兼容。该修复沿用本轮用户报错的修复授权。
