# ADR-0011: Guided pitch review using retained conversion evidence

**Status**: Proposed
**Date**: 2026-10-29
**Owners**: Resonantia maintainers
**Governing specs**: [001](../../specs/001-voice-conversion-engine/spec.md), [003](../../specs/003-webui/spec.md)

## Context and authorization

维护者指出，没有监测工具时用户无法判断跳音及修正方式，并明确同意推进此前讨论的
“程序定位和建议、用户局部试听后决定”流程。本轮授权覆盖该交互、短音频验证及 Web 接入；
不包含长训练、自动整曲转换、自动接受建议或 Git 发布。ADR 审查状态保留 Proposed。

2026-10-30 后续授权：维护者确认局部试听改善，要求推进WebUI并将本次局部修音、页面、
测试和文档提交、推送main及检查CI；诊断工具与录音继续留在本地。此授权不扩大自动转换范围。

## Decision

1. 复用终态任务保存的 F0/合成块，提供只读音高报告。I/O 库负责格式、摘要及只读共享锁；
   F0 库负责有界曲线处理与启发式疑点分析，Web 只负责任务归属、序列化及操作编排。
   不改已有块格式，不把读报告变成恢复或生成操作；缺失/不兼容数据明确不可用。
2. 默认界面显示可疑位置、理由、原声/结果同位置循环试听及建议。八度短暂跳变可产生偏移
   候选；不能确定的情况只标记。不用虚构的准确率，不把未检出当作无错误，也不自动量化旋律。
   高级编辑保留原手动区间，但不是普通用户必须经过的步骤。
3. 短预览保留整曲原输入、分块边界、原 F0 和采样偏移：核验父任务完整配方和计算程序，
   在新任务目录建立新身份的缓存，只复制依赖未变的 F0 和合成块。修音影响到的合成上下文
   整块失效；仍执行原 CLI 的全局 F0/RMS/输出路径，随后裁出听审片段。
   禁止修改父缓存身份、绕过完整身份或把短裁剪后重分析冒充整曲一致预览。
4. 预览复用既有后台任务、单 GPU 互斥、检查点、暂停/恢复和磁盘限制；新可选参数标明预览
   来源及原曲时间。修正前/后片段作为独立结果保留，关闭页面后仍可找到。未改变现有转换 CLI
   的数值实现或部署二进制，避免无关升级使已有任务失去恢复能力。
5. 一次试听只允许短区间变化，并限制需重算的合成块数量。没有完整、相容缓存时明确拒绝
   快速预览，不悄悄退化为整曲模型重算。应用建议和生成完整新版分别由用户触发。

## Alternatives considered

- 只给曲线或改按钮名称：仍要求用户自行诊断，不满足使用门槛要求。
- 对整曲强制调音阶或平滑：可能消除正常滑音/颤音，不采用。
- 裁短输入重新提取 F0：上下文和分块会变化，无法保证预览代表最终结果。
- 新增 Python 推理服务/模型：本次可复用既有 C++/CUDA 能力，不引入运行时依赖。

## Migration and rollback

先完成只读缓存与分析门禁，再接报告/曲线/试听，最后实现独立预览缓存和真实音频对拍。
旧任务记录与块格式保持，新增任务参数仅为可选字段；预览任务不得被当作整曲原版派生。
生产在测试通过且无活动计算时切换 Web 服务和静态页面，计算 CLI 保持原文件。
回退保留全部任务/结果；旧服务不得恢复不认识的预览任务，须使用新版继续。

## Verification and SDD impact

- 只读打开不创建锁、不删 pending、不写 identity；错摘要/链接/活动 owner 拒绝。
- 正常颤音、滑音、真实旋律换音、UV 间隔及短八度异常的正反例；真实《富士山下》缓存验证。
- 新旧配方只允许局部修音差异；完整 F0/合成覆盖、上下文失效、损坏/漂移及暂停恢复门禁。
- 真实短音频的缓存派生预览与相同配置独立完整转换逐样本比较；不降低现有数值门槛。
- 浏览器循环/A-B、采纳/撤销、失效建议、错误/无资产、任务恢复、移动布局与可访问性验证。
- 同步 001/003 spec、DESIGN、TRACEABILITY、PROJECT_STATE；证据见实施记录。
